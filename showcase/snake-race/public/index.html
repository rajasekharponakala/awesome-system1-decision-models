How to read this

Fixed tick. The game moves on a timer. A model must answer before the next tick or its snake keeps going straight, which counts as a missed tick. This measures whether a model is fast enough for a real-time loop.

Free run. Each snake moves as soon as its model answers, so a faster model plays more moves in the same time. Food per 100 moves compares decision quality independently of speed.

Model ms is time spent waiting on the backend, measured by the local server. End-to-end ms adds the hop from browser to server. For a remote API, model ms includes the network round trip.

Mock lanes are a heuristic with simulated latency for testing the harness. Never report their numbers as model results.
