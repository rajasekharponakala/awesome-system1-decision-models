# Contributing

Thanks for helping grow this list.

## What belongs here

- Models, runtimes, SDKs, integrations, tools, benchmarks, and guides for **System 1 decision models**. These are models that return typed, calibrated decisions (Choice / Score / Noul) in a single pass instead of generating text.
- Projects work with any System 1 model (Jev, Laya, Von, …), not only one vendor's.

## Guidelines

- Add one entry per pull request when you can, in the right section.
- Format: `- [Name](https://link): Short description.`, one line, ending with a period.
- Say what the project *does*, and include the license or hardware requirements when they affect whether someone can use it.
- Label performance claims as the authors' own claims unless an independent benchmark backs them up.
- The project must be public and working (no empty repos or placeholder pages).
- Keep the **Use Cases** section model-agnostic and grounded in real deployments or reproducible benchmarks.
